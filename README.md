# Credi-Amigo

Prototipo web sencillo para administrar préstamos personales.

## Incluye
- Registro de clientes
- Creación de préstamos
- Interés simple
- Fecha de inicio y fecha de cobro
- Pagos parciales o completos
- Saldo pendiente
- Estado pendiente / vencido / pagado
- Historial de pagos
- Respaldo y restauración en JSON
- Datos guardados localmente en el navegador

## Cómo abrirlo
Abre `index.html` con Google Chrome, Edge o Safari.

## Importante
Este proyecto es un prototipo local. No incluye autenticación, base de datos en servidor, cifrado, verificación de identidad, contratos, cobranza automatizada ni cumplimiento regulatorio. No debe usarse como plataforma pública de préstamos reales sin desarrollo adicional y revisión legal.
